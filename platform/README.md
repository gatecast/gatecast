# platform/ — API, web app, alerts, deployment

**Owner:** Chris · **Stack:** FastAPI, PostgreSQL, React, Docker

- `platform/api/` — FastAPI backend serving the endpoints in [`docs/contracts.md`](../docs/contracts.md).
- `platform/web/` — React frontend (live map, track-my-flight, predictions).
- Email alerts and deployment config.

## Setup

1. Install Docker Desktop (Windows: with WSL 2).
2. Copy `.env.example` to `.env` in the repo root.
3. Run instructions go here once the services exist.
